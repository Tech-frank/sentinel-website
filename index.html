The governance cycle

What Sentinel does. Every day. Without being asked.

01
Morning checkpoint

Sentinel opens a verified checkpoint at the start of each day — location-confirmed, evidence attached. Miss it, and the day is marked. Permanently.

02
Continuous tracking

Every operating session is tracked from start to finish. Irregular patterns are caught automatically — no one has to be watching for them.

03
Delivery verification

What's claimed is checked against what's measured, the moment it's logged. Anything outside tolerance is stopped before it's accepted.

04
Nightly reconciliation

Sentinel closes the day and reconciles automatically. If something doesn't add up, an escalation is raised. No one needs to notice. It already has.

Once written, the record exists permanently. When something is in dispute, the answer is always in the log.

Record Immutability

Every submission is editable for 24 hours — enough time to correct genuine mistakes. After that, the record locks. Only the Founder can request a change, and doing so leaves a paper trail: the original record is preserved, the change is logged, and a written reason is required. Nothing is quietly modified.

Shadow Mode → Enforcement Mode

Every new site starts in Shadow Mode — the system runs fully in the background, capturing data and calibrating baselines, without alerting anyone or surfacing anything to the Owner. Once the baseline is trusted, an authorized switch moves the site to Enforcement Mode — all dashboards go live, all alerts activate, and the governance cycle is fully visible. The switch requires explicit confirmation, and it is permanent.

The Escalation Promise

When Armina Sentinel raises an alert, it stays on record permanently. It can be resolved — but resolution means providing a written explanation and attaching evidence. The resolution itself is logged. And if no one resolves it before the deadline, the system escalates it to the next severity level automatically. No one needs to notice. No one needs to remind anyone. The system does it.
