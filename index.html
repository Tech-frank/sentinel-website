The governance cycle

What Sentinel does. Every day. Without being asked.

01
Morning anchor

Sentinel opens a 5-minute window. The supervisor checks in, GPS-verified, with a photo. Miss the window — the day is marked MISSED. Permanently.

02
Runtime tracking

Sentinel tracks every generator session — start, stop, duration. Overlap is rejected. Three short runs in 24 hours and Sentinel creates an escalation without being told to.

03
Diesel delivery

Sentinel calculates the variance the moment a delivery is logged. Claimed versus measured. If the tank would overflow, the submission is blocked. No exception.

04
Night anchor

Sentinel closes the day and runs reconciliation automatically. If the variance is high, it creates an L3 escalation. No one needs to notice. It already has.

Once written, the record exists permanently. When something is in dispute, the answer is always in the log.

Record Immutability

Every submission is editable for 24 hours — enough time to correct genuine mistakes. After that, the record locks. Only the Founder can request a change, and doing so leaves a paper trail: the original record is preserved, the change is logged, and a written reason is required. Nothing is quietly modified.

Shadow Mode → Enforcement Mode

Every new site starts in Shadow Mode — the system runs fully in the background for 5 days, capturing data and calibrating burn rates, without alerting anyone or surfacing anything to the Owner. Once the Founder is satisfied with the baseline, they switch to Enforcement Mode. From that point, all dashboards go live, all alerts activate, and the governance cycle is fully visible. The switch requires typing the exact site name as confirmation. It is permanent.

The Escalation Promise

When Armina Sentinel raises an alert, it stays on record permanently. It can be resolved — but resolution means providing a written explanation and attaching evidence. The resolution itself is logged. And if no one resolves it before the deadline, the system escalates it to the next severity level automatically. No one needs to notice. No one needs to remind anyone. The system does it.
